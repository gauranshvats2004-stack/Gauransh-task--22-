# ✦ Project Landing Page (Tailwind CSS)

A modern responsive landing page UI built using **HTML + Tailwind CSS + Ionicons**.  
This project is inspired by SaaS productivity tools like Notion-style dashboards.

---

## 🚀 Features

- Modern SaaS-style landing page design
- Sticky navigation bar
- Hero section with CTA buttons
- Dashboard-style UI cards
- Shadow-based card components
- Ionicons integration
- Clean and minimal UI design
